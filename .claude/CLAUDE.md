## What This System Is

DMAC Assistant wraps Claude Code itself as the agent runtime for MIT BioMicro Center lab users. It is a thin bridge around a containerized `claude` CLI, not a custom agent framework. The main moving parts are:

1. A FastAPI bridge that authenticates users, resolves authorized project directories, starts a per-user Docker container, and relays messages between the chat UI and Claude's `stream-json` output.
2. A Docker image named `dmac-assistant` that contains Claude Code, `uv`, plugins, docs, and the entrypoint.
3. Plugin and docs content that the in-container Claude runtime reads from fixed paths inside the image.

## Load-Bearing Invariants

- Docker mounts are the security boundary. Do not replace that model with ad hoc path checks in bridge code.
- Project data is mounted read-only and output goes to `/data/scratch/`.
- Secrets live only in runtime environment variables and must never be persisted into mounted Claude state.
- `--dangerously-skip-permissions` is an intentional part of the headless bridge model.
- Chat UI credentials are reused as NExtSEEK credentials for the session; do not persist them.
- Session state lives in the mounted `.claude/` tree, not in the bridge.

## Canonical Mount Contract

| Container | Host | Mode |
|---|---|---|
| `/data/projects/{name}` | `~/Library/CloudStorage/Dropbox/DMAC_Data/{name}` (macOS dev) | `ro` |
| `/data/scratch` | `/persistent/scratch/{user_id}` | `rw` |
| `/home/user/.claude` | `/persistent/claude-users/{user_id}/.claude` | `rw` |

The container always sees `/data/projects/`; only the host-side roots change between environments.

## Headless Invocation

```text
claude --print --output-format stream-json --verbose --dangerously-skip-permissions [--resume --session-id <id>]
```

The runtime environment includes `CLAUDE_CODE_USE_BEDROCK=1`, `AWS_REGION`, `AWS_BEARER_TOKEN_BEDROCK`, `NEXTSEEK_USERNAME`, and `NEXTSEEK_PASSWORD`.

## POC vs Post-POC Boundary

Keep the current POC scope narrow. Do not add container pooling, Bedrock token refresh, institutional SSO, retention management, or other deferred capabilities unless a later task explicitly asks for them.

## Conventions When Code Lands

- Python dependencies use `uv`.
- The bridge uses `docker-py`, not `subprocess` around the Docker CLI.
- Plugins read from `/data/projects/`, write to `/data/scratch/`, and receive credentials from env.
- Plugin docs are a primary instruction surface for the in-container Claude runtime.
- Bridge runtime/docs live in `src/dmac_assistant/`, `tests/unit/`, `tests/integration/`, and `docs/bridge/`; keep WebSocket docs aligned with the code and the task specs.
