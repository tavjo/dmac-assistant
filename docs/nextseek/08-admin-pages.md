# Admin Pages

Description of the Admin Pages available on NExtSEEK

### [hashtag](#page-cEt2PLgLtOLJoLhzEg3p-admin-page) [Admin Pagearrow-up-right](https://nextseek.mit.edu/admin/)

This is the built in standard mezzanine admin page associated with the NExtSEEK software suite.

### [hashtag](#page-cEt2PLgLtOLJoLhzEg3p-revise-sample-attributes)

This page allows users to add/remove/edit attributes of Sample Types. This feature is only available on NExtSEEK, as SEEK does not allow for attribute editing. This is very useful when we are working with a new group, and they collect (and want us to include) a new field of a Sample Type that already exists.

### [hashtag](#page-cEt2PLgLtOLJoLhzEg3p-revise-clade-association)

This displays a set of internal databases table specific to NExtSEEK. For more information on Sample Clades, . This page contains interactive tables that allow setting clade color, and assigning new sample types clades.

### [hashtag](#page-cEt2PLgLtOLJoLhzEg3p-admin-sample-retrieval)

This is the same as the sample retrieval page, but just for Admins, who have access to all assets across all projects. The standard sample retrieval page is slightly slower as the retrieval confirms that you have access to the samples that you are trying to download
